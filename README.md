# Дипломный проект по автоматизации тестирования Task-menegment-system-api

---
Проект предназначен для автоматизированного тестирования веб-сайта Task-menegment-system-api. 
Проект нацелен на автоматизацию проверки ключевых функциональностей данного веб-сайта, авторизация, отображение информации о досках, задачах, статистика по пользователям .

Для реализации проекта использовались современные подходы к разработке тестовых фреймворков
Page Object Pattern (POM) - каждая станица представлена отдельным классом, что позволяет отделить логику работы со страницей от тестовой логики, улучшая читаемость и поддержку кода.
Page Elementary Pattern - базовый класс BasePage содержит общие методы для взаимодействия с элементами (например, поиск, клики, ввод текста, ожидание видимости элементов). Это позволяет избежать дублирования кода и облегчает реализацию новых страниц.

## Запуск первого теста

Тихий запуск тестов:

```bash
pytest -q
```

## Запуск тестов с разными ключами

**Базовые:**

```bash
pytest          # стандартный вывод, запускает все тесты
pytest -v       # подробные имена тестов
pytest -q       # тихий режим
pytest -m "api" # запуск только API
pytest -m "ui"  # запуск только UI
pytest tests/test_api/test_statistics.py -v -s --cache-clear --tb=short  # пример
```

Полезные флаги на практике
```bash
#-s   — не захватывать stdout/stderr (удобно для дебага print)
#--lf — запустить только “упавшие” на прошлом прогоне
#--ff — сначала упавшие, потом остальные
#--durations=10 — показать 10 самых долгих тестов

```
## Allure

Результаты прохождения автотестов записываются в каталог allure-results.

Для просмотра отчёта выполнить команду:

```bash
allure serve allure-results
```
